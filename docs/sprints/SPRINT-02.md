# SPRINT-02

## Title

Spring Boot Foundation

---

## Goal

Build the backend foundation using production-ready engineering practices.

---

## Deliverables

Project structure following Clean Architecture.

Common packages:

* config
* controller
* service
* repository
* domain
* dto
* exception
* security
* util

Configuration:

* Spring Profiles
* Global Exception Handler
* Bean Validation
* Structured Logging
* OpenAPI (Swagger)

---

## Requirements

* Java 21
* Spring Boot 3.x
* Maven
* Constructor Injection only
* No field injection

---

## Acceptance Criteria

* Application starts successfully.
* Health endpoint is available.
* OpenAPI documentation loads.
* Validation works.
* Global exception handling is configured.

---

## Out of Scope

* JWT
* User module
* Database entities
* AI
* MCP

---

## Definition of Done

Backend foundation is ready for future feature development.
