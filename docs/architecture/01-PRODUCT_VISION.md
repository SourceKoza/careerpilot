# CareerPilot AI

## Product Vision

**Company:** SourceKoza Labs

**Version:** 1.0

---

# Vision

CareerPilot AI is an AI-powered platform that automates the complete software engineering job application process.

The platform should reduce manual work while keeping the user in control of important decisions.

---

# Problem Statement

Software engineers spend significant time on repetitive tasks:

* Searching multiple job platforms.
* Reading job descriptions.
* Comparing skills with requirements.
* Tailoring resumes.
* Writing cover letters.
* Tracking applications.
* Following up on applications.

Most of this work is repetitive and can be automated.

---

# Solution

CareerPilot AI uses multiple AI agents working together to:

* Discover jobs.
* Analyse job descriptions.
* Match jobs with the user's profile.
* Tailor resumes.
* Generate cover letters.
* Track application status.
* Automate repetitive workflows.

---

Primary Users:

* Full Stack Developers

* AI Engineers

Future:

# Core Objectives

* Reduce manual effort.

# Version 1 Scope

Included:

* User authentication.
* Resume management.
* Job discovery.
* AI job analysis.
* Resume tailoring.
* Cover letter generation.
* Application tracking.
* Multi-Agent orchestration.

---

# Out of Scope

Version 1 will NOT include:

* Mobile applications.
* Payment processing.
* Recruiter portal.
* Social networking.
* Video interviews.

---

# Success Metrics
